# 顾客客服与知识库

管理员进入客服知识库，运行增量构建，打开文档查看片段、模型和维度，并测试 Top-K。顾客打开智能客服，可问购买、账户、订单状态和收货规则。已付款订单不可通过顾客取消，当前版本没有退款。个人订单仍通过我的订单查看。

四篇知识文档作为应用资源维护，按二级标题切分为十段，长段按最多 500 字符切分。每段调用 Embedding 接口，归一化后以双精度向量存 MySQL BLOB。文档哈希不变且模型空间兼容时复用现有向量。重建先生成全部变化片段的向量，再在一次事务写入，失败前原索引仍可用。

查询生成自己的 Embedding，按精确余弦排序，过滤低于 0.34 的片段并取前三。返回的引用由服务端从实际检索集合按片段 ID 匹配。空集合、无效引用和模型拒答会显示证据不足。引用校验能验证关联来源，回答语义准确度仍需真实模型和人工评测。

检索复杂度为 O(片段数 × 维度)，上限 500 个片段用于小型课程语料。较大知识库可分页缓存向量、加入近邻索引、业务分库和混合关键词检索，保留同样的权限与引用验证。
