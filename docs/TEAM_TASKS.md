# 四人分工与独立复现

以下是建议分工，实际贡献由组员根据本人工作和提交记录填写。每位成员应独立启动应用、完成顾客到商家再回到顾客的购买闭环、核对百万行数，并能从题库随机抽题说明实现依据。

| 建议负责人 | 主负责材料 | 独立复现要求 |
|---|---|---|
| A | ER 图、约束、数据生成、完整性报告 | 解释价格快照和库存恒等式，现场复算一笔订单并检查一项约束 |
| B | 业务接口、事务、并发测试 | 对着源码解释库存扣减、状态机、回滚，复现 1205 与 1213 |
| C | 索引、慢查询、浏览器体验 | 对比执行计划，讲清覆盖索引、回表、游标分页，能在页面定位真实数据 |
| D | Docker、复制、日志恢复、发布记录 | 对着配置解释 GTID，独立恢复两笔测试订单并说明截点选择 |

组员分别保留自己的测试时间、执行命令、结果、代码变更和理解记录。教师文档对平时成绩同时出现“四次”和“六次”描述，项目文档覆盖表中列出的六类技术实验。日常报告次数及提交形式以任课教师确认为准。
