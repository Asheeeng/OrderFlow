# 项目现场演示

1. 起动环境后打开 [OrderFlow](http://127.0.0.1:5173)。用三个浏览器上下文分别登录 `demo_customer`、`demo_merchant`、`demo_admin`，密码取本机 `.env`。
2. 顾客打开商品目录，从 `DEMO-TRAIL` 或其他演示商家商品进入详情，加到购物车，选择合成地址，提交订单。展示另一笔待支付订单取消后库存恢复。
3. 对一笔待支付订单模拟支付。切换到商家，在订单处理中输入自选模拟物流单号并发货。回到顾客确认收货。检查订单明细的成交金额、库存及完整状态。
4. 管理员展示平台图表、商品和订单管理及两个角色的账号管理。打开数据库实验，现场运行 COUNT(*)，查看索引、并发、binlog 和复制材料。
5. Navicat 分别连主库和从库，查询 `server_id`、`SHOW CREATE TABLE order_items`、库存行及精确数量。用从库执行 `SHOW REPLICA STATUS`。
6. 运行 [索引实验](MYSQL_EXPERIMENTS.md) 的优化前后 SQL，口述显式基线和行数差。双会话展示库存行锁、RR 或 RC 快照、间隙锁。
7. 运行 `scripts/binlog-lab.sh --isolated-run`。展示误删后的源实例、删除行事件及恢复库中的订单 1 和 2。演练使用独立临时容器。
8. 打开 [答辩题库](DEFENSE_QA.md)。每位组员从不同章节随机抽题，对照项目代码、SQL 或证据解释原理。

## V1.1 三角色演示

1. 管理员打开客服知识库增量构建，查看向量维度和一次 Top-K 检索。再在 AI 数据助手比较两个日期区间，展开工具参数、SQL、来源和图形。
2. 顾客进入智能客服，询问待支付订单取消规则和已付款订单退款，展开命中的片段。再问无关问题展示拒答。
3. 商家进入 AI 库存分析，选择一个在售商品，核对可用数、七日销量、预计可售天数，展示建议与数据库依据。
4. 主动说明当前连接的真实模型或 Mock 协议，展示证据和调用时间。[AI 答辩题](AI_DEFENSE_QA.md) · [AI 验收](../evidence/v1.1.0/README.md)
